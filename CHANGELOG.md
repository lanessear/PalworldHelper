# Changelog

All notable changes to PalworldHelper will be documented here.

The project follows [Semantic Versioning](https://semver.org/) and the structure from [Keep a Changelog](https://keepachangelog.com/).

## [0.6.0] - 2026-07-26

### Added

- Native WPF desktop application shell
- Server profiles with SFTP save discovery and download
- Bundled save parser helper for `Level.sav`
- Save Data overview with players, owned Pals, owner filtering and sortable tables
- Save-aware breeding planner with passive-skill tags and parent candidate details
- Versioned breeding dataset copied beside the executable
- Portable Windows publish workflow with parser helper and third-party notices
- Project documentation, issue templates and contribution workflow
